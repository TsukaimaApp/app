# Project Site (tsukaima.app) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the single-page project site from the design kit as a static, self-contained `site/` tree in the app repo, accurate to Tsukaima 0.9.2 and deployable to GitHub Pages at tsukaima.app.

**Architecture:** Plain HTML + one CSS file + one tiny vanilla JS file, no build step for the page. Fonts are subset once to woff2 by a script and committed. Static checks (validator, external-host and asset-link scan, copy rules, budgets) run from `scripts/site/check.sh` in CI; browser checks (axe, overflow at 360 px, reduced motion, screenshots) run locally with the Playwright Chromium already installed on the VM. A Pages workflow deploys `site/` from `main`.

**Tech Stack:** HTML5, CSS custom properties (the kit's tokens), vanilla JS; fonttools `pyftsubset` + woff2; Node 22 + Playwright 1.56.1 (`npx -y playwright@1.56.1`), `axe-core`, `html-validate`; GitHub Actions (`actions/configure-pages@v5`, `actions/upload-pages-artifact@v3`, `actions/deploy-pages@v4`).

**Spec:** `docs/superpowers/specs/2026-10-21-site-design.md` (read it first; the kit page it updates is `design/ui_kits/site/index.html`, the tokens are `design/tokens/*.css`, the component references are `design/components/{chat,chrome,core}/*.jsx` and `design/ui_kits/tsukaima/chat-screen.jsx`).

## Global Constraints

- Branch `feat/site` off `main`. One commit per task, explicit `git add` paths (never `-A`; never stage `scripts/__pycache__/`).
- Everything under `site/` is published as-is; dev tooling lives in `scripts/site/`, never in `site/`.
- No external request from the page: the only `http(s)://` hosts allowed anywhere in `site/` are `github.com` (paths `TsukaimaApp/app`, `ImranR98/Obtainium`, `NousResearch/hermes-agent`) and `tsukaima.app`. No `<script src>` or `<link>` to a CDN, no Google Fonts, no icon font, no images from other hosts.
- Links, verbatim: Download APK `https://github.com/TsukaimaApp/app/releases/latest`; View source `https://github.com/TsukaimaApp/app`; Obtainium `obtainium://add/https://github.com/TsukaimaApp/app`; Releases `https://github.com/TsukaimaApp/app/releases`; Issues `https://github.com/TsukaimaApp/app/issues`; Obtainium project `https://github.com/ImranR98/Obtainium`; Hermes Agent `https://github.com/NousResearch/hermes-agent`.
- Facts, verbatim where used: "Android 10+", "about 6 MB", "0.9.2", "Connected · Hermes 0.22.2", username + password sign-in, JSON-RPC WebSocket, Kotlin + Jetpack Compose, Material 3, light and dark themes with Material You optional, tablet/foldable two-pane layout; no web build, no iOS.
- Copy rules: sentence case; no exclamation marks in prose; no emoji; 使い魔 is the only ornamental glyph; serif only where the kit uses serif (headings, status lines, wordmark). The forbidden list for `check.sh`: `SSE`, `hm_`, `405B`, `Hermes 4`, `web build`, `token` (as a sign-in credential — the page never mentions tokens), `fonts.googleapis.com`, `unpkg.com`, `cdn.`.
- Light theme only. Tokens are the kit's light values copied into `site/site.css` (page `#F7F4ED`, raised `#FFFDF7`, sunken `#EFEAE0`, hairline `#E6E0D4`, ink `#272220`/`#5D564E`/`#746B61`, accent `#7C6FCF`, pressed `#6A5EBF`, selected `#C9C2F0`, wash/user bubble `#EAE6F8`, ok `#5B8A68`, danger `#B3564E`, warn `#A8823E`, code bg `#272233`, code ink `#D8D3E8`, shadow `0 2px 12px rgba(60,50,40,.10)`, radii 12/14/16/28/10/999, focus ring `0 0 0 2px #7C6FCF`).
- Budgets: `site/fonts/` total ≤ 500 kB; `site/site.js` ≤ 3 kB; `site/img/og.png` ≤ 200 kB; no single file > 1 MB.
- Accessibility: one `h1`; landmarks `header`/`main`/`footer`; every `section` has a heading; `alt="Tsukaima"` on the mark in the nav, `alt=""` on decoration; `:focus-visible` ring; 44 px min targets for links styled as buttons; `prefers-reduced-motion: reduce` disables the dot pulse and the verb cycling.
- Voice wording as the spec's ruling: never say the phone path is offline or vendor-free.

## Review Focus

1. A 360 px wide phone: the hero phone mock, the code blocks and the Settings mock must not cause horizontal page scroll — Task 3 `audit.mjs` asserts `scrollWidth <= innerWidth` at 360 and 390.
2. JavaScript off: the hero status line shows a sensible static verb and the approval demo shows the card — Task 2 `check.sh` asserts the static text "Running shell command…" is in the markup, Task 3 asserts the approval card markup is present without JS.
3. `prefers-reduced-motion: reduce`: no verb cycling and no pulsing dot — Task 3 `audit.mjs` emulates it and asserts the status text is unchanged after 2.5 s and the dot's computed `animation-name` is `none`.
4. The `obtainium://` link on a desktop does nothing: the caption "Opens in Obtainium on your phone" and the plain link to the Obtainium project must sit next to the badge — Task 2 `check.sh` asserts both strings.
5. Fonts blocked or slow: text renders in the fallback stacks and swaps — Task 1 `check.sh` asserts every `@font-face` has `font-display: swap` and every `--font-*` stack ends in a generic family.
